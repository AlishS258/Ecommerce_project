# E-Commerce Sales and Customer Behaviour Analytics

## Project Overview
This project analyzes e-commerce sales data and customer behaviour using Python. It helps understand sales performance, customer purchasing patterns, product categories, and shopping trends.

## Objectives
- Analyze total sales and revenue.
- Identify top-performing product categories.
- Study customer behaviour and repeat purchases.
- Analyze sales by age group, gender, and city.
- Understand payment methods and device usage.
- Analyze customer ratings and delivery time.
- Process sample product images using OpenCV.

## Dataset
- Dataset: E-Commerce Customer Behavior and Sales Analysis
- File: `ecommerce_customer_behavior_dataset_v2.csv`
- Records: 17,049
- Columns: 18
- Format: CSV
- Missing Values: 0
- Duplicate Rows: 0

Note: The dataset contains simulated data.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- OpenCv

## Project Structure
- `main.py` – Main project code
- `data/` – Dataset files
- `images/` – Sample product images
- `processed_images/` – Processed images
- `requirements.txt` – Required Python libraries

## How to Run
1. Install the required libraries using `pip install -r requirements.txt`.
2. Activate the virtual environment.
3. Run `python main.py`.

## Analysis
The project includes sales analysis, monthly trends, product category analysis, customer behaviour, payment methods, device usage, customer ratings, and delivery time analysis.

## Conclusion
This project uses Python data analysis and visualization techniques to understand e-commerce sales and customer behaviour. It also demonstrates basic image processing using OpenCV.
